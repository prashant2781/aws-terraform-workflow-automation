CI/CD pipeline me Lambda deploy kaise hoti hai?
Developer code Git me push karta hai → pipeline trigger hoti hai → code test/build hota hai → Lambda ZIP/package banta hai → Terraform/SAM/Serverless/CLI se AWS Lambda update hoti hai → optional testing + approval + prod deployment hota hai.
Lambda ek AWS service hai jisme function run hota hai.
Lekin function ke andar jo Python/Node.js code, dependencies, handler, env variables, IAM role, timeout, memory etc. hota hai — usko update karna hi deployment hai.

1. Developer code commit karta hai
2. Pull request create hoti hai
3. Code review approve hota hai
4. Merge to dev branch
5. Dev pipeline trigger hoti hai
6. Terraform Lambda ZIP banata hai
7. AWS Lambda update hoti hai
8. API Gateway se test hota hai
9. Same build stage/prod me promote hota hai
